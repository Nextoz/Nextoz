### What I do

**For software teams (contract work)**

- CI/CD and release flows in Azure DevOps
- Infrastructure as code with Bicep and Terraform, so environments can be recreated
- Docker, Kubernetes, Helm and KEDA: deployments, autoscaling and troubleshooting
- .NET backend: new features, upgrades, and legacy code that has to keep running
- Logs, metrics and tracing with OpenTelemetry, OpenSearch and Grafana
- Security in delivery: OIDC and Key Vault instead of long-lived secrets, vulnerable dependencies, and secrets that should never reach a deployment

**For small businesses (AI consulting)**

We find one workflow where AI saves real time, and I build it so it still works in three months. Fixed prices: [karpov.dk/en/ai-consulting](https://karpov.dk/en/ai-consulting/)
